# Free Software Initiatives

Tasks, ideas, and plans for promoting free/open-source software in Persian-speaking communities, primarily in Iran.

## Overview

| File | Focus |
|------|-------|
| [Software](software.md) | Writing, maintaining, and improving free software with Persian support |
| [Books](book.md) | Original books and translations into Persian |
| [Community](community.md) | GNU/Linux and free software adoption in Iranian schools, companies, and culture |
| [Action Items](do.md) | Concrete tasks, commands, and quick-reference notes |

## Principles

- Unix philosophy: write programs that do one thing well
- Free as in freedom (GPL, Debian Social Contract)
- Persian-first, but upstream-friendly
- Practical over theoretical — ship, then iterate

## How to Use

Each file is a living document. Use `- [ ]` for pending tasks and `- [x]` for completed ones. Add notes under any item for context.
