# Introduction

Tasks, ideas, and plans for promoting free/open-source software in Persian-speaking communities, primarily in Iran.

This book tracks actionable work across four areas:

| Chapter | Focus |
|---------|-------|
| [Software](./software.md) | Writing, maintaining, and improving free software with Persian support |
| [Books](./books.md) | Original books and translations into Persian |
| [Community](./community.md) | GNU/Linux and free software adoption in Iranian schools, companies, and culture |
| [Action Items](./action-items.md) | Concrete tasks, commands, and quick-reference notes |

## How to Use

Each chapter is a living document. Use `- [ ]` for pending tasks and `- [x]` for completed ones. Add notes under any item for context.

To build this book locally:

```bash
mdbook serve
```

This will start a local server at `http://localhost:3000` with live reload.
