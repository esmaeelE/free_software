# Principles

These principles guide all work in this project.

## Unix Philosophy

Write programs that do one thing well. Compose small tools. Prefer simplicity.

## Free as in Freedom

GPL, Debian Social Contract, DFSG. Software freedom is non-negotiable.

## Persian-First, Upstream-Friendly

Build for Persian users. Contribute patches upstream. Don't fork unless necessary.

## Practical Over Theoretical

Ship, then iterate. Working software beats perfect designs.
